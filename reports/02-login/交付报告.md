## 设计决策
- **V2 状态管理**：LoginViewModel 使用 @ObservedV2 + @Trace，LoginPage 使用 @ComponentV2 + @Local，确保属性变更时 UI 自动刷新
- **router.replaceUrl 导航**：登录成功后用 replaceUrl 替换当前页，用户无法回退到登录页；步骤四将升级为 Navigation 框架
- **loginApi 可注入**：ViewModel 的 loginApi 属性默认指向 mockLogin，测试时可替换为自定义 mock，无需真实网络
- **错误提示采用 Toast**：客户端校验和 API 错误均通过 promptAction.showToast 展示，与 ApiService 风格一致
- **加载状态管理**：isLoading 控制按钮禁用+透明度+LoadingProgress 显示，防止重复提交
