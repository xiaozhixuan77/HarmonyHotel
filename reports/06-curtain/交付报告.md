## 功能清单
- [x] 全开按钮 — 一键将所有窗帘和窗纱状态设为 open
- [x] 全关按钮 — 一键将所有窗帘和窗纱状态设为 close
- [x] 布帘独立控制 — 左/右窗帘分别控制，支持打开/暂停/关闭/半开四种状态
- [x] 窗纱独立控制 — 左/右窗纱分别控制，支持打开/关闭/半开三种状态
- [x] 状态图标实时反映 — 各区域图标随状态变化切换
- [x] 所有21个窗帘相关 media 图标均已使用

## 设计决策
- 窗帘控制逻辑完全本地模拟（无专用后端 API），与项目设计书一致
- 使用 `cloneCurtain()` 辅助函数规避 ArkTS `arkts-no-untyped-obj-literals` 和 `arkts-no-spread` 限制
- 组件间通过 `@Param` + `@Event` 回调通信，保持与 Light 模块一致的 MVVM 模式
