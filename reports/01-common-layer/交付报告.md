## 设计决策
- **Mock 统一 300ms 延迟**：模拟真实网络延迟，在开发阶段提供真实的异步体验，后续切换到真实 API 时无需修改调用方逻辑
- **ApiService 采用静态方法类**：避免实例化开销，token 作为模块级变量管理，与 PreferencesUtil 配合使用
- **DeviceModels 接口设计与后端 JSON 字段一一对应**：接口属性名与 `getState` 响应 JSON 键名保持一致，避免序列化/反序列化的字段映射
- **PreferencesUtil 独立封装**：Token 和登录信息存储操作独立于 ViewModel，确保数据访问层单一职责
- **401 回调机制**：ApiService 提供 `setOnUnauthorized` 回调注册，由登录模块注入导航逻辑，避免 common 层对 feature 层的反向依赖
