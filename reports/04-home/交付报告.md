## 设计决策
- **内置防抖**：通用 DebounceUtil 的 `T extends Object[]` 类型约束不兼容 number 参数，在 HomeViewModel 内部用 setTimeout/clearTimeout 实现 500ms 温度防抖
- **V2 组件通信**：子组件使用 @Param 接收数据（父→子），@Event 回调（子→父），数据流单向清晰
- **API 可注入**：getRoomStateApi / clickAirBtnApi / setLightModeApi 均可替换，单元测试无需真实网络
- **晚安模式**：调用 setLightMode(103004) 发送全关指令，不走通用场景切换逻辑
- **DND/清理**：纯本地状态切换，无后端 API（与设计书记录的 API Gap 一致）
